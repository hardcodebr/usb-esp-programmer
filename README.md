# USB-C ESP Programmer (HC22002)

A compact **USB-C-to-UART programmer** for the **ESP8266 / ESP32** series with
**automatic reset & boot** — flash with `esptool`, the Arduino IDE, or ESP-IDF
with no button presses ("no boot-button dance"). USB bus-powered.

> 🛒 **Buy:** https://lectronz.com/products/usb-c-uart-esp-programmer-auto-reset-auto-boot
> 🔌 Need isolation? See the [isolated variant (HC22003)](https://github.com/hardcodebr/usb-esp-programmer-isolated).

## Features
- **USB-C**, bus-powered (one cable carries power + data)
- **Automatic reset / auto-boot** — flash with zero button presses
- On-board **RST** and **BOOT** buttons for manual control
- Works out of the box with **esptool**, **Arduino IDE**, and **ESP-IDF**
- Supports **ESP8266, ESP32, ESP32-S2/S3, ESP32-C3**
- Selectable pull-up via a populated 2.54 mm header + jumper cap
- 3.3 V logic; clearly labeled target breakout (TX, RX, EN, IO0, GND, VCC)
